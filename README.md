# 🛒 Smart Fridge Chef (Next.js + FastAPI Premium Edition)

## 🛠️ Enterprise Tech Stack ของทีม PUPA
- **Frontend:** Next.js, Tailwind CSS, shadcn/ui, Recharts
- **Backend:** FastAPI, SQLAlchemy, FastMCP
- **Database:** PostgreSQL (Supabase)
- **AI & APIs:** Gemini 2.5 Flash, OpenFoodFacts API, Spoonacular API

## 📂 โครงสร้างโฟลเดอร์และการพัฒนา (Monorepo Architecture)
- `/frontend` : ส่วนติดต่อผู้ใช้งานแอปพลิเคชันหน้าบ้าน (Next.js)
- `/backend` : ระบบหลังบ้าน สมองส่วนกลางเชื่อม AI และฐานข้อมูล (FastAPI)
